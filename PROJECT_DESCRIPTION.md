# Виртуальная галерея искусств

## Описание

Это комплексное веб-приложение, представляющее собой виртуальную галерею искусств с поддержкой VR, ИИ-курированием коллекций и интеграцией IoT для обратной связи пользователей. Приложение позволяет пользователям просматривать произведения искусства в 3D-окружении, участвовать в виртуальных турах, делать ставки на аукционах и взаимодействовать с ИИ-системой для персонализации опыта.

## Архитектура

### Фронтенд
- **React.js** - компонентный UI фреймворк
- **Three.js** - 3D визуализация галереи
- **WebXR API** - поддержка VR/AR опытов
- **TypeScript** - строгая типизация для лучшей читаемости и поддержки кода

### Бэкенд
- **Node.js с Express** - серверная часть
- **TypeScript** - строгая типизация для лучшей архитектуры
- **PostgreSQL** - основная база данных с поддержкой JSON для метаданных
- **Redis** - кэширование и сессии
- **Socket.IO** - реал-тайм коммуникации

### ИИ и машинное обучение
- **TensorFlow.js** - для разработки моделей ИИ на клиенте и сервере
- **Python скрипты** - для сложных ИИ-вычислений (через API)

### IoT интеграция
- **Raspberry Pi/Arduino** - для подключения сенсоров
- **Сенсоры** - для сбора данных об аудитории

## Установка и запуск

1. Установите зависимости:
   ```bash
   npm install
   ```

2. Установите TypeScript и компилятор:
   ```bash
   npm install -g typescript ts-node
   ```

3. Скопируйте `.env.example` в `.env` и настройте переменные окружения

4. Скомпилируйте TypeScript:
   ```bash
   npm run build
   ```

5. Запустите приложение:
   ```bash
   npm start
   ```

## Разработка

Для разработки с автоперезагрузкой:
```bash
npm run dev
```

## Модульная архитектура

Проект использует модульную архитектуру для обеспечения:

- **Разделения ответственности** - каждый модуль отвечает за определенную функциональность
- **Повторного использования** - модули могут быть легко переиспользованы
- **Тестируемости** - модули легко тестировать изолированно
- **Поддержки** - изменения в одном модуле не влияют на другие

## Типизация

Весь проект использует TypeScript для:

- **Строгой типизации** - предотвращение ошибок во время выполнения
- **Лучшей читаемости** - явное определение структур данных
- **Поддержки IDE** - автодополнение и проверка типов
- **Более легкой поддержки** - понятная структура кода

## Реализованные функции

1. **Система ролей пользователей** - администратор, куратор, сотрудник, организатор туров, участник аукциона
2. **Дашборды** - для каждой роли реализован свой интерфейс управления
3. **Аутентификация и авторизация** - безопасный доступ к ресурсам
4. **Управление экспонатами** - добавление, редактирование, удаление
5. **ИИ-курирование** - автоматическое создание коллекций
6. **Виртуальные туры** - планирование и проведение туров
7. **Аукционная система** - участие в торгах и управление ставками
8. **Система отзывов** - обратная связь от пользователей
