# Виртуальная галерея искусств

## Настройка S3-хранилища

Для хранения изображений в виртуальной галерее используется S3-совместимое хранилище на хостинге beget.com.

### Настройка учетных данных

1. Создайте учетную запись S3 на beget.com (если еще не создана)
2. Получите ACCESS_KEY_ID и SECRET_ACCESS_KEY
3. Добавьте учетные данные в файл `.env`:

```env
S3_ACCESS_KEY_ID=ваш_ключ_доступа
S3_SECRET_ACCESS_KEY=ваш_секретный_ключ
S3_REGION=ru-msk  # для Москвы или ru-spb для Питера
S3_BUCKET_NAME=virtual-gallery-images  # или другое имя бакета
S3_ENDPOINT=https://s3.beget.com
```

### Инициализация бакета

Для создания бакета (если он не существует) выполните команду:

```bash
npm run init-s3
```

### Использование

После настройки система будет автоматически сохранять:

- Загружаемые изображения
- Сгенерированные миниатюры
- Изображения с водяными знаками
- Архивы с изображениями

в S3-хранилище вместо локальной файловой системы.

## Основные возможности

- Загрузка изображений через дроп-зону
- Загрузка архивов (ZIP)
- Загрузка по ссылке
- Генерация миниатюр разных размеров
- Добавление водяных знаков
- Создание NFT для произведений искусства
- Интеграция с ИИ для анализа изображений
- Поддержка виртуальных туров
- Многопользовательский доступ с ролями

## Установка и запуск

1. Установите зависимости:
```bash
npm install
```

2. Настройте переменные окружения в файле `.env`

3. Запустите приложение:
```bash
npm run dev
```

Приложение будет доступно по адресу http://localhost:5000
