# План улучшений 3D-галереи

## Этап 1: Освещение (музейная подсветка)
- Индивидуальные SpotLight для каждого слота картины (направленные сверху вниз)
- Тёплый оттенок подсветки (3200K), узкий угол луча
- Усиление теней от рам картин
- Мягкий отсвет от стен через PointLight
- Потолочные светильники (декоративные цилиндры на потолке)

## Этап 2: Текстуры поверхностей
- Процедурные текстуры пола: паркет (classic/impressionism), бетон (modern), мрамор (renaissance)
- Текстура стен: лёгкая шероховатость через bumpMap
- Плинтусы вдоль нижнего края стен (BoxGeometry)
- Потолочные карнизы (тонкий бордюр по периметру потолка)

## Этап 3: Двери и проёмы
- Арочная форма проёма (ExtrudeGeometry по Shape с дугой)
- Свечение при наведении мыши (emissive)
- Указатель-курсор pointer при hover на двери
- Мягкая подсветка изнутри проёма (PointLight)

## Этап 4: Динамические кнопки залов + LOD
- Кнопки навигации генерируются из конфигурации API (не хардкод HTML)
- Подключить LOD-менеджер: регистрация canvas-меша картины
- LOD работает без перезаписи уже загруженной текстуры высокого качества

## Этап 5: Мини-карта (клавиша M)
- Canvas-overlay в правом верхнем углу
- Схематичный вид сверху: залы (прямоугольники), коридоры (линии)
- Точка текущего положения камеры
- Клик по залу на карте → навигация

## Этап 6: Прогресс-бар загрузки
- Реальный процент: количество построенных залов / загруженных текстур
- Плавная анимация полосы прогресса
- Подписи этапов: «Строим залы...», «Загружаем картины...»

## Этап 7: Замена alert/prompt на toast и встроенные формы
- Кнопка «Аукцион» → toast-уведомление
- Кнопка «Вопрос» → встроенная форма в модалке вместо prompt()
- Подключить toast.js из проекта

## Этап 8: Финальное тестирование
- Проверка всех залов и переходов
- Обновление replit.md
