   ## 🚀 Финальные шаги развертывания:

   ### 1. Загрузить на GitHub:

       cd ai-ml-service
       git push origin main

   ### 2. Создать .env для продакшена:

       # На сервере создать .env файл
       OPENAI_API_KEY=your-openai-key
       JWT_SECRET=your-secure-jwt-secret
       # QDRANT_* уже настроены

   ### 3. Развернуть на beget.com:

       # На сервере с Docker поддержкой
       git clone https://github.com/your-username/ai-ml-service.git
       cd ai-ml-service

       # Создать .env с реальными ключами
       cp .env.example .env
       # Отредактировать .env

       # Запустить
       docker-compose -f docker-compose.prod.yml up -d

   ### 4. Проверить работу:

       # Health check
       curl http://your-server:8000/health

       # Test API
       curl -X POST http://your-server:8000/api/v1/rag/query \
         -H "Authorization: Bearer your-jwt-token" \
         -H "Content-Type: application/json" \
         -d '{"query": "Test query"}'
