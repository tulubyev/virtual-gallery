---
name: Работа по одной задаче
description: Ограничение пользователя на создание и запуск подзадач в этом проекте.
---

Разбираться по одной задаче. Не создавать, не предлагать и не запускать новые подзадачи.

**Why:** Пользователь повторно потребовал остановить рост числа подзадач: «так мы будем бесконечно изменять код».

**How to apply:** Работать только над текущим запросом, не расширять его дополнительными исправлениями и не запускать следующую задачу по собственной инициативе.
