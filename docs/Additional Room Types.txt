   ## Additional Room Types: Themed Galleries and Exhibition Spaces

   ### Overview

   Implement a flexible room theming system that allows curators to create immersive, contextually appropriate
   exhibition spaces beyond the basic gallery hall. This feature will enhance visitor engagement by providing
   atmospheric environments that complement artwork themes and improve the overall virtual gallery experience.

   ### 1. Room Type System Architecture

   #### Data Models

       interface RoomType {
         id: string;
         name: string;
         description: string;
         category: 'classical' | 'modern' | 'themed' | 'special';
         baseTemplate: RoomTemplate;
         customizationOptions: CustomizationOption[];
         lightingPreset: LightingPreset;
         audioPreset?: AudioPreset;
         supportedArtworkTypes: ArtworkCategory[];
         visitorCapacity: number;
         accessibilityFeatures: string[];
       }

       interface RoomTemplate {
         geometry: RoomGeometry;
         materials: MaterialPreset[];
         decorations: Decoration[];
         interactionPoints: InteractionPoint[];
       }

       interface RoomInstance {
         id: string;
         typeId: string;
         galleryId: string;
         customizations: RoomCustomization[];
         artworks: ArtworkPlacement[];
         currentVisitors: number;
         status: 'active' | 'maintenance' | 'closed';
       }

   #### Database Schema Extensions

       * room_types table for predefined templates
       * room_instances table for created rooms
       * room_customizations table for user modifications
       * artwork_placements table for 3D positioning

   ### 4. 3D Implementation Details

   #### Room Generation Pipeline

       1. Template Loading: Load base geometry and materials
       2. Customization Application: Apply user modifications
       3. Artwork Placement: Position artworks in 3D space
       4. Lighting Setup: Configure lighting based on presets
       5. Optimization: LOD, culling, and performance tuning

   #### Three.js Integration

       class RoomGenerator {
         generateRoom(roomType: RoomType, customizations: RoomCustomization[]): THREE.Group {
           const roomGroup = new THREE.Group();

           // Generate geometry
           const geometry = this.createRoomGeometry(roomType.baseTemplate.geometry);
           roomGroup.add(geometry);

           // Apply materials
           this.applyMaterials(roomGroup, roomType.baseTemplate.materials, customizations);

           // Add decorations
           this.addDecorations(roomGroup, roomType.baseTemplate.decorations);

           // Setup lighting
           this.setupLighting(roomGroup, roomType.lightingPreset);

           return roomGroup;
         }
       }

   #### Performance Optimizations

       * Instancing: Reuse geometries for similar elements
       * LOD System: Level-of-detail for distant objects
       * Frustum Culling: Hide objects outside camera view
       * Texture Atlasing: Combine textures for efficiency
       * Progressive Loading: Load room elements on demand
