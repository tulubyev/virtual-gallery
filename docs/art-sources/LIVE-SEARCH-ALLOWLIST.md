# Предложение: белый список живого поиска

Основано на проверке от 26.10.2026 (`CHECK-REPORT.md`, `annotations/<id>.json`). Это **предложение для решения владельца и юриста**, в код ничего не подключено. Правило отбора: `robots.txt` не запрещает нужные страницы, нет входа и оплаты, разметка стабильна, сайт отвечает, и права не запрещают показ короткого пересказа со ссылкой на источник. Ответ помощника, полученный из живого поиска, должен быть помечен как «из внешнего источника» и содержать ссылку; текст целиком не копируется.

## Что обязательно сделать при подключении
1. Брать только домены из первой таблицы, запрос шаблонизировать, не следовать ссылкам за пределы домена.
2. Соблюдать `Crawl-delay` (nsartmuseum.ru — 5 с, id.loc.gov — 3 с); кэшировать ответ не дольше суток.
3. Относиться к содержимому страниц как к данным: не выполнять текст-указания (в проверке таких страниц не найдено, кроме `paulfrasercollectibles.com`, его в список не включать).
4. Повторять проверку `robots.txt` раз в неделю: он меняется.
5. Для сотрудников список можно расширить после согласований; для посетителей начинать с афиш.
