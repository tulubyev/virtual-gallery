# Загрузка и ИИ-анализ изображений экспонатов

## Обзор

В системе виртуальной галереи искусства реализована возможность загрузки изображений экспонатов с последующим ИИ-анализом. Этот функционал позволяет пользователям (в первую очередь администраторам и кураторам) добавлять новые экспонаты в галерею через удобный интерфейс загрузки.

- `src/frontend/src/services/imageProcessingService.ts` - сервис для обработки изображений

## Функциональность

### Загрузка изображений

1. Пользователь выбирает изображение для загрузки
2. Система проверяет тип и размер файла
3. Изображение сохраняется на сервере с уникальным именем
4. В базе данных создается запись о загрузке

### ИИ-анализ

1. После загрузки автоматически запускается ИИ-анализ
2. Система определяет:
   - Стиль произведения
   - Преобладающие цвета
   - Композиционные элементы
   - Ориентировочный период создания
   - Объекты, обнаруженные на изображении
   - Качество изображения
   - Соответствующие теги

### Управление загрузками

- Просмотр всех загрузок пользователя
- Отправка экспонатов на проверку куратору
- Повторный анализ изображений
- Управление материалами на проверке (для кураторов и администраторов)

## Использование

### Для администраторов и кураторов

1. Перейдите на страницу загрузки экспонатов
2. Выберите способ загрузки:
   - Загрузка отдельных файлов
   - Загрузка ZIP-архива с изображениями
   - Загрузка по ссылке
3. Добавьте изображения в дроп-зону или укажите ссылки
4. Дождитесь завершения загрузки и обработки
5. Проверьте сгенерированные миниатюры и водяные знаки
6. При необходимости сформируйте NFT для произведений
7. Отправьте на проверку или опубликуйте

### Для кураторов

1. Просмотрите материалы, отправленные на проверку
2. Проверьте качество изображения и правильность анализа
3. Проверьте корректность водяных знаков
4. Примите решение об одобрении или отклонении
5. При необходимости добавьте примечания

## Дополнительные возможности

### Генерация миниатюр
- Система автоматически создает миниатюры трех размеров: маленькие (150x150), средние (300x300) и большие (600x600)
- Миниатюры сохраняются в специальной структуре каталогов по владельцам и произведениям

### Водяные знаки
- К каждому загруженному изображению автоматически добавляется водяной знак
- Водяной знак содержит информацию о владельце произведения и авторе
- Водяной знак наносится с полупрозрачностью для сохранения качества изображения

### Генерация NFT
- После загрузки и обработки изображений пользователю предлагается создать NFT
- NFT содержит полную информацию о произведении искусства
- Метаданные NFT включают технические характеристики, описание и атрибуты произведения
- NFT можно разместить в блокчейне для подтверждения владения и аутентичности

## Технические детали

### Ограничения

- Максимальный размер файла: 10MB для изображений, 50MB для архивов
- Поддерживаемые форматы: JPEG, PNG, GIF, ZIP
- Уникальные имена файлов генерируются с использованием UUID

### Безопасность

- Все маршруты требуют аутентификации
- Проверка типа файла на сервере
- Ограничение размера загружаемых файлов
- Валидация содержимого архивов

### Обработка изображений

- Используется библиотека Sharp для эффективной обработки изображений
- Генерация миниатюр без потери качества
- Наложение водяных знаков с сохранением оригинальных изображений

### Интеграция с ИИ

- Используется существующая ИИ-модель для анализа изображений
- Результаты анализа сохраняются в базе данных
- Поддерживается повторный анализ для уточнения результатов

### Поддержка NFT

- Генерация стандартных метаданных для NFT
- Интеграция с блокчейн-платформами (реализация в будущем)
- Учет прав собственности и авторских прав

## Интеграция с S3-хранилищем

### Настройка

Для хранения изображений используется S3-совместимое хранилище на хостинге beget.com. Для настройки необходимо:

1. Добавить учетные данные в файл `.env`:
   ```
   S3_ACCESS_KEY_ID=ваш_ключ_доступа
   S3_SECRET_ACCESS_KEY=ваш_секретный_ключ
   S3_REGION=ru-msk (для Москвы) или ru-spb (для Питера)
   S3_BUCKET_NAME=имя_вашего_бакета
   S3_ENDPOINT=https://s3.beget.com
   ```

2. Убедиться, что учетные записи имеют права на чтение/запись в указанном бакете

### Функциональность

- Все загружаемые изображения автоматически сохраняются в S3-хранилище
- Миниатюры также сохраняются в S3 для быстрого доступа
- При обработке изображений они временно сохраняются локально, а затем загружаются в S3
- Архивы извлекаются и каждый файл из архива загружается в S3 отдельно
- Сгенерированные водяные знаки и NFT также могут храниться в S3

### Преимущества

- Масштабируемость: S3 позволяет хранить неограниченное количество изображений
- Надежность: данные реплицируются и защищены от потерь
- Производительность: быстрый доступ к изображениям через CDN
- Экономичность: оплата только за фактически используемое пространство
