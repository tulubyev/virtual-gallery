 ## 🚀 Полное руководство по запуску и тестированию AI/ML сервиса

   Да, задача полностью выполнена! 🎉

   ## ✅ Что было реализовано:

   ### Python AI/ML Core Service - полностью функциональный

       * FastAPI приложение с асинхронными эндпоинтами
       * OpenRouter интеграция вместо прямого OpenAI API
       * Image Analysis: Анализ изображений через GPT-4 Vision
       * PDF Processing: Извлечение текста, OCR, chunking, векторизация
       * RAG System: Семантический поиск и генерация ответов
       * Vector Operations: Qdrant для хранения и поиска embeddings
       * Database Integration: PostgreSQL для метаданных
       * Async Processing: Фоновые задачи для тяжелых операций
       * Health Checks: Мониторинг и диагностика
       * Error Handling: Graceful degradation и логирование

   ### Инфраструктура

       * Docker контейнеры для всех сервисов
       * API Gateway (Node.js) для маршрутизации
       * База данных PostgreSQL с pgvector
       * Vector Database Qdrant (Cloud/Local)
       * Redis для кэширования и очередей

   ### Интеграция с OpenRouter

       * Автоматическое переключение между OpenRouter и OpenAI
       * Fallback embeddings при недоступности
       * Оптимизированные модели (Claude-3-Haiku для текста)

   #### Тестирование API эндпоинтов:

   1. Анализ изображений:

       curl -X POST http://localhost:8000/api/v1/images/analyze \
         -H "Content-Type: application/json" \
         -d '{
           "image_url": "https://example.com/artwork.jpg",
           "artwork_id": 123
         }'

   2. Обработка PDF:

       curl -X POST http://localhost:8000/api/v1/pdfs/process \
         -H "Content-Type: application/json" \
         -d '{

           "document_id": "doc_123"
         }'

   3. RAG запросы:

         -H "Content-Type: application/json" \

   ### 🔧 Возможные проблемы и решения

   #### OpenRouter API:

       * Проверьте OPENROUTER_API_KEY в .env
       * Убедитесь что на аккаунте OpenRouter есть кредиты

   #### База данных:

       * Проверьте подключение к beget.com
       * Убедитесь в корректности DATABASE_URL

   #### Qdrant:

       * Проверьте QDRANT_URL и QDRANT_API_KEY
       * Для локальной разработки: QDRANT_URL=http://localhost:6333

   #### Docker проблемы:

       # Очистить все
       docker system prune -a
       docker-compose down -v

       # Пересобрать
       docker-compose up --build --force-recreate
