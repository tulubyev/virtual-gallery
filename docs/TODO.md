# Виртуальная галерея искусств - План разработки

## Исследование структуры проекта

### Архитектура и технологии
- **Фронтенд**: React.js, Three.js, WebXR API, TypeScript
- **Бэкенд**: Node.js с Express, TypeScript, PostgreSQL, Redis, Socket.IO
- **ИИ и машинное обучение**: TensorFlow.js, Python скрипты
- **IoT интеграция**: Raspberry Pi/Arduino, сенсоры

### Установка и запуск
1. Установите зависимости: `npm install`
2. Установите TypeScript и компилятор: `npm install -g typescript ts-node`
3. Скопируйте `.env.example` в `.env` и настройте переменные окружения
4. Скомпилируйте TypeScript: `npm run build`
5. Запустите приложение: `npm start`

### Реализованные функции
1. **Система ролей пользователей** - администратор, куратор, сотрудник, организатор туров, участник аукциона
2. **Дашборды** - для каждой роли реализован свой интерфейс управления
3. **Аутентификация и авторизация** - безопасный доступ к ресурсам
4. **Управление экспонатами** - добавление, редактирование, удаление
5. **ИИ-курирование** - автоматическое создание коллекций
6. **Виртуальные туры** - планирование и проведение туров
7. **Аукционная система** - участие в торгах и управление ставками
8. **Система отзывов** - обратная связь от пользователей
9. **Интеграция с S3-хранилищем** - для хранения изображений
10. **Загрузка изображений** - с поддержкой drag-and-drop, архивов и ссылок
11. **Обработка изображений** - с применением ИИ-анализа
12. **3D-визуализация галереи** - с поддержкой VR
13. **Генерация NFT** - для произведений искусства

## Анализ реализованных маршрутов

### authRoutes.ts
- POST `/register` - регистрация нового пользователя
- POST `/login` - аутентификация пользователя
- POST `/refresh` - обновление токена (требует валидный токен)
- POST `/logout` - выход из системы (требует валидный токен)
- GET `/verify` - проверка токена (требует валидный токен)

### userRoutes.ts
- GET `/profile` - получение профиля пользователя (требует аутентификации)
- PUT `/profile` - обновление профиля пользователя (требует аутентификации)
- GET `/preferences` - получение предпочтений пользователя (требует аутентификации)
- PUT `/preferences` - обновление предпочтений пользователя (требует аутентификации)
- GET `/favorites` - получение избранных произведений пользователя (требует аутентификации)
- POST `/favorites/:artworkId` - добавление произведения в избранное (требует аутентификации)
- DELETE `/favorites/:artworkId` - удаление произведения из избранного (требует аутентификации)
- GET `/history` - получение истории взаимодействий пользователя (требует аутентификации)

### artworkRoutes.ts
- GET `/` - получение всех произведений искусства
- GET `/:id` - получение информации о конкретном произведении
- GET `/search/:query` - поиск произведений по запросу
- GET `/filter/:tags` - фильтрация произведений по тегам
- POST `/` - создание нового произведения (требует аутентификации)
- PUT `/:id` - обновление информации о произведении (требует аутентификации)
- DELETE `/:id` - удаление произведения (требует аутентификации)
- GET `/recommendations` - получение рекомендованных произведений для пользователя (требует аутентификации)
- GET `/:id/similar` - получение похожих произведений
- POST `/:artworkId/collections/:collectionId` - добавление произведения в коллекцию (требует аутентификации)
- GET `/:id/analytics` - получение аналитики по произведению

### galleryRoutes.js
- GET `/` - получение всех галерей
- GET `/:id` - получение информации о конкретной галерее
- GET `/:id/rooms` - получение комнат галереи
- POST `/` - создание новой галереи
- PUT `/:id` - обновление информации о галерее
- DELETE `/:id` - удаление галереи
- GET `/:id/recommended` - получение рекомендованных произведений для галереи

### aiRoutes.js
- GET `/recommendations` - получение ИИ-рекомендаций (требует аутентификации)
- GET `/collections/generate` - генерация ИИ-коллекции (требует аутентификации)
- POST `/analyze-image` - анализ изображения произведения (требует аутентификации)
- GET `/similar/:artworkId` - получение похожих произведений
- POST `/train-model` - обучение модели рекомендаций (требует аутентификации)
- GET `/personalize-route` - персонализация маршрута по галерее (требует аутентификации)
- POST `/predict-engagement` - предсказание вовлеченности пользователя (требует аутентификации)

### userManagementRoutes.js
- GET `/` - получение всех пользователей (только для администраторов)
- GET `/role/:role` - получение пользователей по роли (только для администраторов)
- PUT `/:userId/role` - обновление роли пользователя (только для администраторов)
- DELETE `/:userId` - удаление пользователя (только для администраторов)
- GET `/stats` - получение статистики по пользователям (только для администраторов)

### artworkUploadRoutes.js
- POST `/upload` - загрузка изображения произведения
- POST `/:uploadId/analyze` - запуск ИИ-анализа загруженного изображения
- GET `/:uploadId/analysis` - получение результатов ИИ-анализа
- POST `/submit-for-review` - отправка произведения на проверку куратору
- GET `/users/:userId/uploads` - получение всех загрузок пользователя
- GET `/submissions-for-review` - получение материалов на проверке (только для кураторов и администраторов)
- POST `/submissions/:submissionId/approve` - одобрение произведения (только для кураторов и администраторов)
- POST `/submissions/:submissionId/reject` - отклонение произведения (только для кураторов и администраторов)
- POST `/:uploadId/reanalyze` - запрос повторного анализа изображения
- POST `/generate-nft` - генерация NFT для произведения искусства

### iotRoutes.js
- POST `/devices/register` - регистрация нового IoT-устройства
- POST `/devices/:deviceId/connect` - подключение IoT-устройства
- POST `/devices/:deviceId/disconnect` - отключение IoT-устройства
- POST `/devices/:deviceId/data` - обработка данных от IoT-устройства
- POST `/devices/:deviceId/command` - отправка команды IoT-устройству
- GET `/devices/status` - получение статуса всех IoT-устройств
- GET `/devices/:deviceId/status` - получение статуса конкретного устройства
- GET `/feedback/:galleryId` - получение агрегированной обратной связи от IoT-сенсоров
- POST `/devices/:deviceId/heartbeat` - симуляция сигнала "сердцебиения" устройства
- POST `/initialize` - инициализация IoT-системы

## Проблемы в архитектуре
- Несоответствие между импортируемыми TypeScript маршрутами в server.ts и фактически существующими JavaScript маршрутами в backend/routes/
- Некоторые компоненты в App.tsx не определены (ArtworksPage, GalleriesListPage)
- Необходимо привести архитектуру к единому стеку (TypeScript)
